# `/e2e/integration/shortcut-listeners` Architecture

Checks keyboard shortcut bindings.

## Files
- **`on-load-register-clear-current-tab-default-url.test.ts`**: Tests the shortcut to clear the current tab's default URL.
- **`on-load-register-reset-current-tab-to-default-url.test.ts`**: Tests the shortcut to reset the current tab to its default URL.
- **`on-load-register-reset-or-close-current-tab-to-default-url.test.ts`**: Tests the shortcut to reset or close the current tab.
- **`on-load-register-set-current-tab-default-url.test.ts`**: Tests the shortcut to set the current tab's default URL.
