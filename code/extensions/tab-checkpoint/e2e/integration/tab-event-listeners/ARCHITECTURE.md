# `/e2e/integration/tab-event-listeners` Architecture

Checks behavior when tabs are created, closed, pinned, or moved to groups.

## Files
- **`on-close-delete-default-url.test.ts`**: Tests deleting the default URL when a tab is closed.
- **`on-create-pinned-set-default-url.test.ts`**: Tests setting a default URL when a pinned tab is created.
- **`on-pin-set-default-url.test.ts`**: Tests setting a default URL when a tab is pinned.
- **`on-set-to-group-set-default-url.test.ts`**: Tests setting a default URL when a tab is moved to a group.
