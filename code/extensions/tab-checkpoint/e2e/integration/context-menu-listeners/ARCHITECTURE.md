# `/e2e/integration/context-menu-listeners` Architecture

Checks context menu interactions.

## Files
- **`on-load-clear-current-tab-default-url.test.ts`**: Tests clearing the default URL from the context menu on load.
- **`on-load-reset-current-tab-to-default-url.test.ts`**: Tests resetting the current tab to the default URL.
- **`on-load-set-current-tab-default-url.test.ts`**: Tests setting the default URL from the context menu on load.
